What this website collects

The ARRIVA website is a static informational site built with pure HTML and CSS. We do not collect personal data from website visitors:

  • No cookies: This website does not set or read tracking cookies, session cookies, or advertising identifiers.
  • No analytics scripts: We do not embed Google Analytics, Mixpanel, Meta Pixel, or any third-party behavioral analytics scripts.
  • No external network calls: All typography (Fraunces, Inter) and icons are self-hosted locally on this domain. Browsing this website initiates zero requests to external third-party servers.

Hosting infrastructure

This website is hosted on Google Firebase Hosting. As with standard internet hosting infrastructure, Firebase servers may automatically log basic HTTP request metadata (such as visitor IP addresses, browser user-agent headers, and requested resource paths) to deliver web pages, maintain network security, and defend against denial-of-service attacks.

ARRIVA does not inspect, export, or monetize these server-level access logs. For further information, refer to Google Cloud's data privacy documentation.

External links

This website contains links to external services, including GitHub, Google Play, and email clients. Once you leave this site, your browsing activity is subject to the privacy terms and practices of the third-party destination.

Changes to this policy

We may update this studio policy from time to time to reflect operational or hosting adjustments. Any changes will be published directly on this page along with a revised effective date.
