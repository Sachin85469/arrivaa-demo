Interface overview

What it does

Tourist Guide helps travelers explore destinations across Maharashtra with confidence. Each destination profile provides curated historical background, operating hours, entry charges, traveler notes, and estimated visit durations.

The trip planning module organizes multiple stops into sensible day itineraries based on travel group style (solo, friends, or family) and pacing preferences. A Kotlin route planner sequences stops to reduce backtracking across city roads.

To assist travelers across linguistic regions, on-device translation enables instant speech and text translation between English, Hindi, and Marathi. Translation models execute locally through Google ML Kit without uploading text to external servers. A phrasebook with native pronunciation covers common transport, food, and safety phrases.

In urgent situations, an emergency SOS button launches the system phone dialer pre-populated with emergency dispatch (112) or opens the SMS client with pre-filled GPS coordinates. Actions rely on Android Intent resolution, so nothing is transmitted without your explicit physical tap.

How it works

Destination information is synchronized from a cloud database hosted on Supabase and cached locally in an on-device Room SQLite database. Once downloaded, place profiles and itineraries remain accessible even without network reception.

Mapping utilizes a dual approach: Google Maps SDK delivers urban place searches and street-level views, while osmdroid renders offline vector contour maps for mountain trails and fort treks where cellular networks drop.

An optional travel chat connects through a lightweight proxy server on Render to Anthropic's Claude API. API credentials reside securely on the backend, authenticated via a private token exchange.

Under the hood

Tourist Guide is engineered natively in Kotlin and Java, targeting Android 14 (API level 34) with compatibility back to Android 7.0 (API level 24).

  • Architecture: AndroidX, Material Design components, ConstraintLayout, Room SQLite database, Retrofit2, and Ktor client.
  • On-Device Machine Learning: Google ML Kit on-device translation for Marathi, Hindi, and English.
  • Mapping Engine: Dual integration combining Google Play Services Maps with osmdroid offline vector topography.
  • Data Storage: Supabase authentication and PostgREST client with PostgreSQL Row-Level Security policies.
  • Licence: Open-source under the MIT licence.
