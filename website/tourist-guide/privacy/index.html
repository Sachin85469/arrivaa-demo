1. Who We Are

ARRIVA is an independent software studio based in Pune, Maharashtra, India, founded and run by developer Sachin Bableshwar. This policy covers the Tourist Guide Android application [confirm package name from release build: com.arriva.touristguide or com.arriva.touristguideapp].

2. Data We Collect

Account information

If you create an optional user account, your email address and display name are stored in Supabase. Account registration is optional; core destination browsing, phrasebook translation, and offline maps work without an account.

Location data

When you use mapping or nearby search features, the app accesses your device GPS coordinates to display your position and calculate routes. Location is accessed while the app is actively in use [confirm from release build: foreground service location permission used during active SOS emergency mode].

Audio and voice

If you use spoken input in the translator, the app accesses the microphone. Speech recognition models run on-device; audio recordings are not stored or transmitted to external servers.

Storage and offline files

The app caches destination details and map tiles in local application storage [confirm from release build: WRITE_EXTERNAL_STORAGE declared for Android 12 and below only for saving offline map tiles].

Chat interactions

If you use the optional AI travel assistant, your questions are forwarded through our backend server hosted on Render to the Anthropic API. The proxy does not log or persist message contents to disk.

Place reviews and feedback

If you choose to submit a destination review or rating, the text and optional user-submitted photo are stored in Supabase and Cloudinary respectively.

What we do NOT collect

We do not collect advertising identifiers, device telemetry fingerprints, contact address books, phone logs, or background tracking data.

3. Why We Collect This Data

Every data point collected serves an explicit user-facing feature: location for navigation and routing, optional email for account sync, audio for speech translation, and review submissions for community destination notes. We do not sell data, build advertising profiles, or monetize user information.

4. Permissions Explained

The permissions requested by Tourist Guide correspond directly to specific in-app features:

Permission Purpose Scope
INTERNET Sync place data from Supabase, retrieve weather, and stream AI chat responses Granted by system
ACCESS_NETWORK_STATE Detect offline connectivity before making network calls Granted by system
ACCESS_FINE_LOCATION Pinpoint user location on map and pre-fill emergency coordinates Runtime prompt when opening maps
ACCESS_COARSE_LOCATION Approximate location fallback for regional weather Runtime prompt when opening maps
RECORD_AUDIO Spoken input for on-device Marathi, Hindi and English translation Runtime prompt when tapping microphone
POST_NOTIFICATIONS Trip reminders and download completion updates [confirm from release build] Runtime prompt on Android 13+
WRITE_EXTERNAL_STORAGE Cache offline map tiles on legacy devices [confirm from release build: Android 12 and below only] Runtime prompt on Android 12 and below
FOREGROUND_SERVICE_LOCATION Maintain location awareness during active SOS distress feature [confirm from release build] While SOS feature is actively running

Note on emergency calling and messaging: The application does not declare SEND_SMS, CALL_PHONE, or accessibility services [confirm from release build]. Emergency calling and SMS are initiated via Android Intent actions (Intent.ACTION_DIAL and Intent.ACTION_SENDTO), which open your phone's native dialer or messaging app and require your physical confirmation before sending.

5. Third-Party Services

The application interacts with the following external service providers to support specific features:

  • Supabase: Provides account authentication and destination database storage. Subject to Supabase's privacy policy.
  • Google Play Services & Maps SDK: Used for map rendering and location resolution. Subject to Google's privacy policy.
  • Google ML Kit: On-device translation models run locally on your hardware; no translation text is uploaded to Google.
  • OpenWeatherMap: Destination weather forecast retrieval. Only approximate regional coordinates are transmitted.
  • Anthropic (Claude): Powers AI travel assistant responses forwarded through our Render backend proxy.
  • Cloudinary: Stores user-submitted photos attached to destination reviews.
  • NVIDIA API: [confirm if narrative storytelling API is enabled in release build; subject to NVIDIA terms of service].

6. Data Retention and Deletion

Local data (bookmarked places, downloaded trail maps, cached trip plans) is stored on your device in a Room SQLite database. You can clear this data at any time via Android application settings or by uninstalling the application.

Cloud account data stored in Supabase can be deleted directly in-app [confirm in-app navigation: Settings > Profile > Delete Account]. You may also submit a deletion request via email to sachinbableshwar1828@gmail.com with the subject "ARRIVA: Account Deletion Request" [confirm deletion turnaround timeframe: typically processed within 7 to 30 business days].

For full instructions, visit our dedicated Account & Data Deletion page.

7. Security

All data transmitted between the application and backend services uses HTTPS with TLS encryption. API credentials for cloud services are managed server-side and excluded from public version control.

8. Children's Privacy

Tourist Guide is a general-audience travel planning tool. We do not knowingly collect personal information from children under 13 (or under 18 under India's Digital Personal Data Protection Act, 2023). If we become aware that personal data of a minor has been gathered without parental consent, we will promptly delete it.

9. Your Rights

You may request access to, correction of, or permanent deletion of your personal data at any time. Users in India may exercise statutory rights under the Digital Personal Data Protection Act, 2023. International users may exercise applicable data protection rights under relevant regional legislation.

10. Changes to This Policy

We may periodically update this policy as new app features are introduced. The effective date at the top of this page indicates the date of latest revision. Continued use of the app constitutes acceptance of the updated policy.
