About

ARRIVA was started by Sachin Bableshwar, a developer based in Pune, India. The studio focuses on native Android applications, backend services and developer tools. Every project is open-source under the MIT licence and published on GitHub.

We believe useful software should work offline, avoid unnecessary data collection and be honest about what it does.
