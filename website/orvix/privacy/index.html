ORVIX Privacy Policy

ARRIVA ORVIX — Local AI Bridge Interface

Effective date: November 3, 2026

In development

ORVIX is currently in active developer prototyping and has not yet been released or distributed to the public.

By architectural definition, ORVIX is designed to execute exclusively on your local machine, connecting to an Ollama server running on loopback IP 127.0.0.1:11434. It does not transmit prompt texts, code, model responses, or machine telemetry to external cloud servers.

Architectural Privacy Guarantees

When ORVIX is published, its design guarantees the following data safety boundaries:

  • Strict local loopback: Communication is restricted to localhost sockets. No telemetry is phoned home to ARRIVA or third-party brokers.
  • No cloud logging: Prompts, context documents, and generated tokens remain in volatile local memory or local developer project files chosen by the user.
  • No behavioral analytics: The software contains no user tracking beacons, demographic collectors, or diagnostic telemetry reporting.

A comprehensive privacy specification will be finalized and published here prior to general software distribution.
