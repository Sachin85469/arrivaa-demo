# ARRIVA: 30-Day Social Launch Plan

## Objective
Attract relevant users to ARRIVA products and learn which content drives product interest, clicks, trials, and repeat use. Prioritize real product demonstrations over generic brand posts.

## Platform roles
- **Instagram:** product discovery, short demos, stories, feedback.
- **LinkedIn:** credibility, practical use cases, milestones, product updates.
- **YouTube:** Shorts repurposed from vertical videos; longer walkthroughs when useful.

## Content pillars
1. Product demos and use cases (40%)
2. Practical tech and AI explainers (20%)
3. Behind-the-scenes building (20%)
4. Product updates and user feedback (20%)

## First nine posts
1. **Meet ARRIVA** — Carousel. Introduce the brand and tagline. CTA: Follow the journey.
2. **The three products** — Carousel. Tourist Guide, NEXUS, ORVIX; one sentence each. CTA: Which would you like to explore?
3. **ORVIX in action** — Reel/Short. Screen recording of the actual local Ollama workflow. CTA: See the setup / try it if available.
4. **A real problem, a practical solution** — Carousel focused on one verified product use case.
5. **One feature, one benefit** — Carousel or Reel. Show one working feature.
6. **Behind the build** — Reel. Show a real iteration, test, or bug fix.
7. **Try the product** — Post. Invite users only if a working public/test build is available.
8. **Help shape the next update** — Poll or carousel with two genuine options.
9. **What we learned this month** — Recap actual progress and invite feedback.

## Four short video scripts
### 1. Product reveal (20 sec)
- 0–3s: "We built [PRODUCT] to help with [REAL PROBLEM]."
- 3–8s: Show the problem or workflow.
- 8–15s: Screen-record the product solving the task.
- 15–20s: "Explore [PRODUCT] at [WORKING LINK]."

### 2. One feature (15 sec)
- 0–2s: "Here's one useful thing you can do with [PRODUCT]."
- 2–10s: Show the feature working.
- 10–13s: State its real benefit.
- 13–15s: "Try it at [WORKING LINK]."

### 3. Behind the build (25 sec)
- 0–3s: "Here's what building [PRODUCT] actually looks like."
- 3–9s: Show design/code/test process.
- 9–17s: Show a real improvement or bug fix.
- 17–22s: Show the result.
- 22–25s: "Follow ARRIVA for the next update."

### 4. ORVIX local workflow (20 sec)
- 0–3s: "Want to experiment with an API workflow without starting with a paid hosted API?"
- 3–8s: Show Ollama running locally.
- 8–15s: Show ORVIX exposing the actual API workflow and a real test request.
- 15–20s: State prerequisites clearly and direct viewers to the verified setup guide.
- Do not claim zero cost overall; local hardware, electricity, and model requirements still apply.

## Measurement
Track each post's topic, format, reach/views, watch time, profile visits, link clicks, sign-ups/first use, and feedback. Judge success by qualified interest and actual product use, not follower count alone.

## Before publishing
- Replace all bracketed placeholders.
- Add verified product links and social profile URLs.
- Confirm which products are publicly available versus still in development.
- Use only real screenshots, features, and results.
- Do not buy followers or fabricate testimonials.
